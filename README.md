# Static File Server

A simple Node.js server for serving static files (HTML, CSS, JS) from a specified directory.

## Usage

1.  Clone the repository.
2.  Install dependencies: `npm install`
3.  Configure the `public` directory (or any other) for static files.
4.  Start the server: `node server.js`
5.  Access files in your browser (e.g., `http://localhost:3000/index.html`).

## Configuration

*   The server listens on port 3000 (configurable in `server.js`).
*   Static files are served from the `public` directory (configurable in `server.js`).
